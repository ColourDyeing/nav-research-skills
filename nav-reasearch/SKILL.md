# 导航方向调研与选题

用中文回答，保留有助于继续检索的英文术语。按读者当前的问题决定起点：初次接触方向时先建立全貌；已经有精读卡或候选想法时，直接从证据和最相近的工作开始。只问会实质改变结论的问题。只有宽泛主题时，可以先给子方向和初步阅读顺序，将场景、设备、学制等未知条件留到筛选课题时处理。

## 从一个方向得到可核查的技术路线

1. 界定应用场景、研究对象和时间范围。查近期进展时实际检索，记录截止日期、实际访问的来源、可复用的中英文检索词和重要覆盖限制。根据方向选择学术索引、出版方、会议论文集或学位论文库。无法联网时，用给定材料作有范围的综述，说明哪些近期判断待查。
2. 用综述找分类和术语，沿代表作追溯奠基工作，并查后续引用、同期竞争方案和相反结果。按题名、作者、DOI 或带版本的 arXiv 标识核对文献，区分预印本、会议版与期刊扩展版。对决定结论的主张回到实际可读的原文，附稳定链接；只有摘要时标明依据。
3. 围绕同一个问题比较各路线。按需列出观测输入、核心假设、状态与约束、在线可用信息、典型失效条件和代表作。比较导航性能时核对传感器配置、参考真值、场景、评价维度与统计口径。例如，比较城市定位方法时，先确认两者是否使用相同的地图先验、遮挡条件以及水平或三维误差。条件不同则分别陈述各自支持的结论。
4. 读者问到热点时，在路线比较后直接回答“近年大家在集中解决什么问题”。每个热点点名不同团队的工作、年份和原文，用一句话解释它们共同检验了什么、结论在哪些条件下仍有分歧。只有一篇新作支撑的方向标为探索性线索。声称发文量增长时给出检索口径和数量依据。

## 遴选高被引代表作和前沿论文

给方向书单时默认同时覆盖下面两类；读者指定只看某类、某场会议或某个时期时按其范围筛选。先按研究问题筛出相关论文，再比较候选。用一篇已知相关论文检查检索词能否命中，并用近期会议论文集或期刊在线发表目录补查索引可能漏掉的新作。将同一工作的预印本、会议版和期刊扩展版关联起来，注明新增贡献；共用同一实验的版本只算一份验证证据。

- **高被引代表作。** 在同一细分问题、相近发表年代和同类文章中比较被引次数。说明它代表哪条路线、后续研究继承了哪项模型、数据集或评测方法；有条件时链接一篇实际采用它的后续论文。综述与原创工作分别标记。优先在同一可访问索引（如 OpenAlex 或 Semantic Scholar）按 DOI 或题名及作者核对条目，逐篇给被引次数、数据源、条目链接和查询日期。多个版本合并计数时注明口径，不累加不同平台的计数。首选索引缺失时可换源并单列；均查不到则写“被引次数未核实”，可凭后续采用证据推荐为路线代表，保留高被引判断待核。
- **高新颖度前沿论文。** 以用户指定窗口为先，未指定时通常从近两三年检索并写明起止时间。逐篇点名最接近的已有方法，说明新增的能力、放宽的假设或解决的具体失效情形，再给出支持该判断的实测、消融、跨场景验证、推导或独立复现及其边界。根据可读原文定位到关键图表或章节。近期发表、期刊声誉和作者的自评都不足以单独支持高新颖度。新作即使被引很少也可入选；只有摘要、证据不足或尚待同行评审时，标明具体状态与待核问题。某类缺少合格论文时如实说明。

### 每篇推荐要给读者什么

在入选理由中给出比较对象。高被引代表作可以列同路线、相近年代候选作的计数作参照，或给出后续采用它作为基线的实例。判断近期论文的新颖度时，同时检索最接近的同期工作，并指出二者差异的原文依据。若一篇新作的主要价值是发现简单基线在特定场景已达到相似精度，可作为“近期实证对照”推荐；若与同期工作的差异尚待核实，标明“创新程度待核”。优先呈现影响读者选择的比较，交代数据划分、指标与定位到表或章节的链接。

用表格或短条目呈现。每篇包含 **类别｜原题名、作者（可用首位作者等）、年份｜发表出处｜文章链接｜被引次数及来源日期｜入选理由与精读问题**。同一篇兼具代表性和前沿性时可双标，在阅读顺序中仅列一次。

- 期刊论文写期刊全称；会议论文写会议全称、届次或年份，区分主会和 workshop。仅有预印本时写平台和版本，正式出处待核。以出版方或官方论文集核对题名、出处、版本和发表状态，发现勘误或撤稿时说明其对推荐的影响。
- 文章链接直达 DOI、出版方文章页或官方论文集的单篇页面；有可合法访问的开放全文可另附链接，标明与发表版的关系。只有预印本时链接对应版本。原文链接与计数来源各指向对应条目；同一书单共用计数来源和查询日期时可在表头统一交代。推荐依据落到该文实际贡献，并标出全文、摘要或外部采用证据的来源。

## 把书单变成阅读顺序

按“建立概念 → 理解基线 → 比较近期工作 → 核查争议”安排少量互补文献，篇数随用户要求与证据调整。每篇给可核验的题录和原文入口，说明为何此时读、读完应能回答什么问题。已核对全文时可指出值得先看的小节、公式或图表。已有同版精读卡时链接到卡，用一句话说明重读价值或接下来要补的证据。

## 把疑问变成可验证的课题

从路线比较或精读卡中选一个具体矛盾，例如某项改善究竟来自新增观测，还是来自更有利的测试条件。为首选课题另做一次针对问题本身的检索：用“待估计量＋失效条件”及同义词查早期直接工作，再沿后续引用和近期发表追踪同一限制是否已被解除。读者关注深度学习时，查新也应覆盖处理同一问题的传统方法。例如，调研卫星信号遮挡对定位精度的影响时，可从 `GNSS signal blockage` 和 `positioning accuracy` 开始检索。对照论文时检查遮挡如何定义、参考真值如何获得，以及开阔路段和遮挡路段是否分别报告了误差。

向读者推荐首选切入点时，在推荐旁给出最接近的原始论文链接，写清“已有工作验证到哪里、候选问题具体多出什么、哪项证据会改变建议”。明确区分论文明确排除的条件、全文中未单列的结果、当前只读到摘要而无法核实的细节。检索范围或可读材料尚不足时，将该点列为待查候选，指出最值得先核对的论文与问题。

完整选题请求通常给出两三个可比较的候选。每个写明研究问题、预期贡献、所需数据与真值、可复现的基线、最小对照实验、评价指标，以及什么结果会削弱假设。理论类课题可改用待证命题、成立条件、已有定理与反例。结合读者可用的设备、代码、算力和时间说明优先尝试哪一个，以及第一个能决定是否继续的实验或推导。如果排序取决于某项未知资源，给出条件化建议。

在排序前先明确读者最看重的条件，如创新空间、能否用已有数据区分两种解释、验证成本。为优先候选提出一个有竞争力的替代解释，找支持与挑战该想法的证据，并说明什么观测能区分两种解释。查到已有工作覆盖原设想时，收窄、改写或放弃该候选，并说明哪篇论文改变了判断。

## 与 nav-reader 交接

- 使用读者指定项目中的精读卡。需要按个人方向或已读情况推荐时，依照同级 [nav-reader 的记录规则](../nav-reader/references/reading-records.md)读取相关画像和历史，按版本匹配。首次使用没有档案时，从本次问题和材料起步。用于外部检索的关键词取自公开的研究主题，个人档案留在本地。
- 推荐精读时，在阅读顺序或首选课题之后附一条可以直接复制的 `$nav-reader` 请求，填入真实题名、原文链接或本地路径，以及读完要作的判断。若选题取决于前作是否已解决某项失效问题，优先选能改变判断的那篇，要求定位相关假设、数据划分或关键实验。读者已要求实际精读时，直接依照 [nav-reader](../nav-reader/SKILL.md) 完成指定论文的精读、归档与记录。单纯列入书单不产生阅读记录。
- 读者带着卡片回来时，从卡中提取有出处的结论、实验条件和待核问题；与其他代表作对照，必要时回到原文。更新受影响的路线判断或课题排序，说明哪条证据改变了建议。调研结果默认在对话交付，读者指定调研文档或项目路径时按要求落盘。
