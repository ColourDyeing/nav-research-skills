# 导航实验的绘图口径

按当前数据和任务选用以下规则；未知字段或实验定义不能靠名称猜测。

## 时间与坐标

- 检查时间单位、历元起点、GPS/UTC/设备单调时钟及采样率；需要时处理已知时差。不得默认 GPS 秒等于 UTC，或默认数组第 i 行代表同一历元。
- 不同采样率可按已说明的容差匹配，或在重叠区间插值参考真值；记录方法、容差和未匹配数量。不要跨长时间失锁段插值或连线，不做无依据的外推。航向角跨 360° 时先按角变量处理。
- 明确 ENU、NED、ECEF 或投影坐标，检查经纬度的度/弧度、高程基准和坐标原点。局部轨迹优先米制 ENU；经纬度不能直接当作米，不直接对经纬度差求水平欧氏误差。可使用 pyproj 转换，但转换参数必须可追溯。
- 平面轨迹 East 为横轴、North 为纵轴，`ax.set_aspect('equal', adjustable='box')`；3D 轨迹也应保持相同长度单位的比例，除非明确标注垂向放大。
- 普通预览和配色演示可直接展示已有坐标。有可靠参考且用于精度比较时，在图中标识 Reference 或参考轨迹，在图注或交付说明注明已知的来源。没有参考时，只比较解之间的空间差异。只有关键路段的差异在最终栏宽难以辨认时，才加等比例局部放大并标出对应路段。
- 不擅自旋转、平移、尺度拟合轨迹以降低误差。用户要求 ATE/RPE 或轨迹配准时说明参考系、SE(3)/Sim(3)、时间间隔和配准方法。

## 误差和统计

- 同历元同坐标系误差为 estimate − reference。ENU 分量是带符号误差；水平误差 `sqrt(e_E**2 + e_N**2)`，三维误差 `sqrt(e_E**2 + e_N**2 + e_U**2)`。
- 分量 RMSE 为 `sqrt(mean(e_axis**2))`；水平 RMSE 为 `sqrt(mean(e_E**2 + e_N**2))`；不能把两个分量 RMSE 的算术平均当成水平 RMSE。标准差、平均误差与 RMSE 含义不同；标准差注明 ddof。
- 水平误差 ECDF 直接对有效完整样本排序，`y=arange(1,n+1)/n`，使用 `step(..., where='post')`；显示最小值之前的 0 概率并在最大值达到 1。不用平滑拟合 CDF，不能默默删除大误差。P50/P95 明确样本及分位数插值方法，例如 NumPy `method='linear'`。
- 数据缺失、非数值、Inf、失锁和离群点分别识别。为计算必须剔除 NaN/Inf 时记录数量；原始失锁和大误差默认保留或单独标注。时间序列保留缺测位置，避免把断点两侧连成连续有效轨迹。
- 箱线图标明中位数、四分位数、须定义；不隐藏离群点。重复实验可展示各次结果与区间；只有单次轨迹时不编造置信区间。相关历元不能轻率当作独立样本估计置信区间。
- 每个面板记录时间起止（缺时间时记录样本序号范围）、有效样本数及是否使用共同历元。快速预览默认全程；有意截取局部时序时，从实际入图历元生成起止时间，写入配套图注。若 RMSE、ECDF 或分段统计覆盖全程，在图注中注明统计区间与有效历元数。分段图沿用同一时间原点，标实际边界或给出段号到时间的对应关系，说明边界历元归属。遮挡、失锁等事件须有输入标记。显示抽稀与统计分开，统计使用指定区间的全部有效样本。
- 正文明确要求定量比较时，按问题选一个读数，例如 P95，或水平误差 ≤ 阈值的历元数除以该方法的有效历元数。用实际数据计算并在图、图注或表中给出。不同方法分母不同时逐方法报告，分母为零时标为无有效样本。只有已知应有历元总数时才报告解的可用率。按需选分位数或不确定性展示，不默认叠加多种统计标记。

## 图形细节

- 误差时序：有已知时间则标时间及其单位，缺时间按原始顺序标“样本序号”，纵轴误差 (m)；ENU 子图共用时间轴。只在有参考意义时绘制零线。采样密集时降低线宽，而不是默认平滑。
- CDF：横轴说明水平/垂直/三维误差，纵轴可为 CDF 或百分比，刻度与标签口径一致。
- 遮挡、静止、动态和失锁区间可用浅灰底或细参考线标记，图注说明依据；不要根据曲线形态臆测场景。
- 算法数量超过清晰辨识能力时分组/拆图。物理量跨度很大时考虑对数坐标并明确标注；不要无说明截断坐标轴制造优势。
- IMU、GNSS、Wi-Fi、蓝牙、气压计与磁力计的原始序列，先核对各传感器单位、轴定义与时间戳再比较；不要暗中去偏、归一化或滤波。
