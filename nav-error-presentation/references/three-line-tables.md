# 通用三线表制作风格

## 基本结构

- 白底黑字，无背景色块、无竖线、无逐单元格网格。
- 三条主体横线为顶线、表头与正文之间的分隔线、底线。
- 需要跨列表头时，可在所属列下增加局部细横线；不要为每个数据行添加横线。
- 合计、汇总或不同数据块确有分隔需要时，可使用少量细线或留白，避免破坏简洁性。

## 线条与字体

| 元素 | 参考参数 |
| --- | --- |
| 顶线、底线 | 黑色，约0.85 pt |
| 表头分隔线 | 黑色，约0.55 pt |
| 跨列表头局部线 | 黑色，约0.45 pt |
| 正文 | 统一衬线字体，通常8–10 pt |
| 标题、表头 | 与正文协调，通常9–10 pt |
| 必要脚注 | 通常7–8 pt，并以最终阅读尺寸确认清楚 |

推荐DejaVu Serif，期刊指定字体时服从期刊。字号是视觉起点，不以缩小文字作为容纳过多内容的首选方法。不要固定表格的宽高、行列数量或比较对象结构。

## 表头与对齐

- 表头准确说明各列含义，列名尽量简短；必要缩写在脚注定义。
- 单位可放在列名、跨列表头或表题中，但作用范围必须清楚。不同量纲不能被同一个含糊单位统括。
- 标签列采用便于阅读的左对齐或一致的居中方式；数值列按小数点、右侧或统一居中对齐。
- 同一指标的位数及显示格式一致，列内对齐。缺失值使用清楚符号，并在必要时说明；不能用0替代缺失。
- 避免人为截断过长标签，必要时合理换行或调整列宽。结构服从当前数据和展示要求。

## 数值、精度与强调

- 表格只展示已提供的数值，不自行计算统计量、变换单位、推断单位或决定指标。
- 小数位和有效数字由当前任务确定，可随指标不同而变化；不默认保留两位小数。
- 如需单位转换或数值舍入，由任务明确后执行，并保留原始精度，避免把展示后的数字重新作为原始数据。
- 默认普通黑色数值。用户要求突出最优值时，明确哪些列参与、在哪些行内比较、越大还是越小更好，以及并列时如何处理。
- 不能默认所有数值列均“越小越好”；不能把样本数、标识、状态或其他非性能列也按最优指标处理。
- 若展示精度下并列，不能任意突出一个值为唯一最优；具体并列标注方式由任务决定。
- 加粗仅是已声明规则下的视觉强调，不代表统计显著性或因果结论。

## 标题、脚注与源文件

表题简洁描述实际内容。脚注仅解释单位、符号、缺失值、精度及加粗等读表所需信息，不带入历史分析的条件、结论或等待状态。

如任务需要可编辑交付，可提供CSV、电子表格或LaTeX源文件。数值文件保留可用精度；LaTeX宜采用booktabs，跨列表头与特殊字符需正确处理。不能用电子表格截图替代原生高质量三线表导出。
