# 误差序列图制作风格

## 适用内容

用于展示已经准备好的导航误差序列。比较对象可以是算法、设备、传感器、试验条件或其他实际对象；误差量、分量、时间或自变量含义由当前任务提供。

本文仅约定视觉语言，不规定子图如何分布，也不提供任何误差计算或数据筛选规则。

## 字体与文字

- 使用英文科研图中的简洁文字及统一衬线字体。推荐DejaVu Serif；期刊指定字体时服从其要求，不混用多种不协调字体。
- 以最终阅读尺寸为准：轴名及图例通常8–10 pt，刻度通常8–9 pt，标题通常9–11 pt；这些是起始范围，不是必须照抄的固定字号。
- 名称和单位写在坐标轴上，推荐`Quantity Error (unit)`。位置、速度、角度、时延等各自采用实际单位，不默认用米、厘米或角度。
- X轴写清真实含义及单位。绝对时间、时间系统、相对时长与其他自变量不能互相误标。
- 标题简短，缩写需在图注或正文定义。面板标题如有，应具有实际意义，不替代轴名及单位。
- 刻度格式匹配数据范围，不能因小数位不足导致多个刻度显示为同一个数值，也避免不必要的长小数。

## 点状序列与配色

- 默认采用彩色点状序列。点应在真实阅读尺寸可辨认，密集时不过分粗重。
- 建议点符号为实心小圆点；起始大小约1.4–1.7 pt，图例点约4 pt，再根据密度、导出尺寸和工具效果调整。
- 默认不加连接线；点状序列自然避免跨缺测区间连线。若当前任务另有线型要求，再按要求调整。
- 比较对象与颜色的映射由具体任务明确，同一对象在各图及图例中保持一致。

可选参考色：

| 颜色 | 色值 |
| --- | --- |
| 蓝 | `#0048D8` |
| 红 | `#E31A1C` |
| 绿 | `#008A58` |

颜色列表不代表软件、优劣、排序或必须出现三个对象。对象较多时补充有辨识度的颜色及点形，并核查图例能否清楚区分。颜色不得暗示未经说明的性能结论。

## 网格、边框与刻度

| 元素 | 参考参数 |
| --- | --- |
| 主网格 | 实线，`#888888`，约0.55 pt |
| 必要的次网格 | `#B0B0B0`，约0.35 pt，避免过密 |
| 边框 | `#222222`，约0.65 pt |
| 刻度 | 向内；线宽约0.55 pt |
| 背景 | 白色 |

网格置于数据后方，保持比浅淡默认网格更清楚，但不要压过误差点。上边及右边刻度按当前图的阅读需要设置，不因此增加多余的轴标签。

## 范围与超限显示

- 显示范围由当前任务确定，不设固定阈值。直接比较的图若使用不同范围，应明确标注，防止视觉误读。
- 仅在任务明确限制显示范围且存在超限数据时，考虑边界上/下三角标记，并在图例或图注解释。
- 边界标记使用对应序列颜色、清楚的小符号；可按连续超限区段标记，避免把整条边框填满。
- 图形裁切和原始数值分开，不能为适应显示范围改写数据、平滑或删点。
- 不因套用本风格自动设置放大图、固定范围或任何布局结构。

## 图例与说明

图例使用实际对象名称及与数据一致的颜色、点形；位置以不遮挡序列且阅读自然为准，不固定位置或列数。图注只解释实际展示内容、缩写、单位及必要符号，不复制旧任务结论。
