# 科研图表导出与质量检查

## 导出

- 默认输出PDF、SVG和原生1200 dpi PNG；具体任务另有要求时调整。
- 使用原生绘图或排版对象导出，不对低分辨率截图插值放大。
- PDF嵌入字体；SVG保留可编辑文字及矢量线条，避免整幅图表变成一张位图。
- 在明确的物理尺寸导出，避免自动裁切意外改变排版宽高。具体尺寸与布局由当前任务决定。
- 缩略图只供浏览，不能替代论文用文件。若另行导出预览，名称应与正式导出清楚区分。

## 展示准确性

- [ ] 名称、单位、图例与所提供数据含义一致，没有旧对象或旧任务标签。
- [ ] 时间或自变量标签准确；未套用特定时间系统的固定文字。
- [ ] Y轴标注了实际量或分量名称及单位。
- [ ] 数值格式足以区分刻度；表格精度和列内格式遵循当前要求。
- [ ] 配色、符号与图例一致，不在不同图中调换同一对象的颜色。
- [ ] 没有为美化图形自行删点、抽样、平滑、填补缺失或改写数值。
- [ ] 显示裁切如有发生已说明，超限符号清楚且没有掩盖异常存在。
- [ ] 最优值强调仅按当前任务指定规则执行；比较范围和优劣方向正确。
- [ ] 没有自动添加分析指标、统计结论或其他图形。

## 视觉验收

- [ ] 在最终论文或报告阅读尺寸检查，而非只看屏幕放大效果。
- [ ] 字号、点大小、网格和边框的轻重协调。
- [ ] 标题、坐标轴名、单位、图例、刻度和脚注均未被裁切或互相遮挡。
- [ ] 图例没有盖住关键序列，表头没有覆盖正文。
- [ ] 三线表无竖线、无密集单元格网格，数字清楚对齐。
- [ ] 表格脚注清楚，横线长度及跨列表头范围正确。
- [ ] 打开实际导出文件或等比例预览检查，不能仅凭生成程序未报错认定合格。

## 文件与范围

- [ ] 所有读写均在用户授权工作区内。
- [ ] 仅改样式时原数值及非目标文件没有被意外改变。
- [ ] 导出格式、尺寸、分辨率和文件名符合当前任务要求。
- [ ] 必要时提供数值文件或排版源文件，内容与展示一致。
- [ ] 说明文档及链接指向当前成果，不把归档版本作为默认入口。

本清单检查展示质量；分析与统计正确性的核查属于具体分析任务，不由本skill另行规定。
