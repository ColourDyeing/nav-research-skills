# 通用导航误差图表展示

只负责**已计算好的误差序列及统计数值的展示风格**。可用于位置、速度、姿态、航向、时间等导航相关误差，以及不同传感器、设备、方法和算法的比较。展示规范不绑定某种定位技术、软件、系统组合、测站组织或分量名称。

## 适用任务与边界

- 按当前任务提供的数据含义、指标、单位及比较对象制图制表。
- 不制定坐标转换、误差计算、统计计算、历元对齐、样本选择或时间窗口规则；这些由具体分析任务确定。
- 不默认使用某组分量、某种方法名、固定误差范围、特定时间标签、单位或小数位。
- 不规定子图数量、分布、方向、组内结构、面板顺序或固定物理尺寸。布局交给当前任务；本skill仅检查最终排版是否清楚。
- 不附代码、数据适配程序、运行命令或固定模板。采用当前任务合适的绘图与排版工具落实以下规范即可。

## 工作流程

1. 读取当前任务要求和已准备的数据，明确需要展示的序列与表格。已有要求足够时直接执行；缺少影响正确展示的名称、单位、范围或精度时再针对性询问。
2. 依据[误差序列图风格](references/error-series.md)设置文字、点状序列、配色、网格和坐标轴。布局完全按当前任务组织。
3. 依据[三线表风格](references/three-line-tables.md)呈现提供的数值；指标、单位、精度及强调规则服从当前任务。
4. 依据[导出与质量检查](references/export-checklist.md)核对物理阅读尺寸、清晰度、遮挡、数值显示和文件完整性。
5. 交付用户要求的图表及必要说明，不自动增加其他分析、图形类型或统计结论。

## 核心视觉规范

### 误差序列图

- 英文科研排版、白色背景、清楚边框、统一字体。
- 默认采用**彩色点状序列**，较深网格，刻度向内。
- 量或分量名称及单位放在Y轴，例如`Position Error (m)`、`Velocity Error (m/s)`、`Heading Error (deg)`；实际内容由任务提供，不能把示例当作固定标签。
- 子图如需名称或编号，应标识实际比较内容；不以缺失Y轴标签的方式只在顶部写量名。是否使用子图标题及如何编号由当前任务决定。
- 比较对象名称和颜色对应关系由任务指定；相同对象在同一交付中保持一致。建议颜色供选择，见详细规范，不与任何软件名称绑定。
- X轴文字及单位准确反映所提供的时间或自变量，不固定使用某种导航时间系统。

### 三线表

- 白底黑字、无竖线，顶线、表头分隔线及底线清晰；必要时增加跨列表头的局部细横线。
- 表头、单位、有效数字和小数位清楚、一致；不同指标可采用不同精度。
- 数值、指标、单位和最优值强调规则均由任务确定，不固定为RMSE，不假设所有指标越小越好。
- 未要求突出最优值时保持普通数值排版。要求加粗时，先确定比较范围、优劣方向、显示精度和并列处理，再一致执行。
- 仅列解释当前表格所必需的脚注；不带入旧任务的设置、数据状态或结论。

## 导出默认值

- 默认提供矢量PDF和SVG，以及从原生绘图/排版对象直接导出的**1200 dpi PNG**；当前任务另有格式要求时以其为准。
- PDF嵌入字体，SVG尽量保留可编辑文字；不把整张文字图表栅格化冒充矢量输出。
- 在实际排版尺寸检查可读性。提高dpi只提高像素密度，不替代合理字号及清楚排版。
- 表格如需可编辑数值或排版源文件，按任务提供CSV、电子表格或LaTeX；不因使用本skill自动要求额外交付格式。

## 本地使用与维护

只读写当前用户授权的工作区。当前用户要求严禁上传网络，图表、数据和技能文件仅在本地处理，不上传、推送或在线发布。仅改样式时保留原数值及非目标成果，并核对未被意外改变。不把历史结果、文件名或状态说明复制到新任务。

本skill为工作区内的规范文档，可独立搬运；不依赖旧分析目录或归档版本，也不表示已安装为全局skill。
