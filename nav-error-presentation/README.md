# 📊 navigation-error-presentation

**通用导航误差序列图与三线表的英文科研展示规范**

[返回技能总览](../README.md) · [AI 技能入口](SKILL.md)

## 技能定位

用于已计算误差序列及已有统计数值的绘图、制表与样式统一。覆盖位置、速度、姿态、航向、时间等导航误差，可用于不同传感器、设备、方法和算法的比较。

| 项目 | 说明 |
| :--- | :--- |
| 技能名称 | `navigation-error-presentation` |
| 文档版本 | 本地整理版 · 2026-11-24 |
| 输入 | 已准备的误差序列或统计数值，以及字段含义、单位和本次展示要求 |
| 默认交付 | 矢量 PDF、SVG、原生 1200 dpi PNG |
| 资源形式 | Markdown 规范与检查清单；不附绘图代码或固定模板 |
| 软件要求 | 不指定软件；由当前任务选用合适工具 |

技能负责展示风格。误差计算、坐标转换、历元对齐、统计指标和样本选择由具体分析任务确定；子图布局、显示范围、分量名称及比较对象也按当前任务组织。
