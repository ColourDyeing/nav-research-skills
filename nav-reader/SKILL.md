# 导航文献精读

## 从输入找到可核对的原文

| 用户给了什么 | 如何阅读和定位 |
| --- | --- |
| 附件、本地 PDF、扫描件、页面截图、Word 或文本文件 | 直接读所给材料，保留原路径或附件名。遇到双栏、扫描页或乱码，检查页面图像，必要时对相关页做 OCR，再对照原图核实公式、表头、单位和小数点。截图只覆盖可见部分。 |
| 期刊、会议、学校论文库、知网等落地页或 PDF 直链 | 优先读能访问的出版方或学校全文，记录实际使用的版本。网页用小节、图表号和段首定位，PDF 可补页码。仅有目录、登录页或摘要时继续找同版本的可访问原文。 |
| DOI、arXiv 编号或链接、LaTeX 源文件 | 解析标识符，保留指定的 arXiv 版本号。优先采用适合当前问题的 HTML 或 PDF；公式提取有歧义时可读同版 TeX 的主文件和所引用章节，对照出版版或渲染页核对编号。 |
| 题名、参考文献、BibTeX/RIS、Zotero 条目或链接 | 先查条目中已有的附件、DOI 或稳定链接；能访问对应文献库时再取条目及附件。无标识符时按题名、作者、年份和出处匹配；若多个版本会改变结论且无法确定目标，再请读者选择。 |
| 粘贴正文、摘要或选段 | 保留作者提供的章节和段落顺序；缺少页码时用章节和段首定位。读者限定范围时按限定范围阅读。 |

同一论文收到多个入口时合并线索，记录实际阅读的原文及版本。PDF 过大、提取失败或章节不全时，尝试同版本 HTML、已有本地附件或可读源文件；会议版与期刊扩展版分别取证。检索结果和书目信息可以帮助找全文。只能读到摘要或节选时在卡首注明范围，将结论限于已读内容。只有题录时报告匹配结果和取得原文所缺的信息，不登记为已读。

## 阅读顺序

1. 先看题目、摘要、结论和关键图表，找到研究问题和作者最重要的主张。再回到方法、实验和附录核对支撑条件。阅读目的已明确时，优先回答该问题；用户只说“精读”时，从论文自身的问题出发。
2. 根据文献体裁组织笔记。**期刊论文**沿核心主张追踪方法变化、基线和证据，指出适用条件。**学位论文**先写一份简短章节导读，说明科学问题如何贯穿各章、哪几章提出自己的方法、各章共用或更换了哪些数据和假设，给出与读者目的相关的优先阅读章节。**会议论文**突出本次发表的具体贡献、与已有方案的差异及该版本实际展示的实验，列出影响判断的未交代细节。综述类按问题分类、文献覆盖和比较依据阅读，理论类按定义、假设、推导与适用范围阅读；可与上述体裁组合。
3. 在覆盖论文主要贡献的基础上，解释决定结论的导航细节。融合方法可沿“观测输入 → 状态与约束 → 估计输出”解释关键公式，核对坐标系、时间基准或同步方式。实测定位论文关注场景、参考真值、基线信息条件、配准方式、误差维度、统计区间及失锁处理。授时论文优先核对参考钟、钟差或频差、稳定度指标及平均时间。数值连同单位、对照对象和适用条件一起记录。
4. 在每项关键主张、数值或有争议的解读旁写可复查的位置，优先用“§4.2，表 3，第 2 行”或“式 (7) 后第 1 段”。必要时区分正文页码和 PDF 页序。无页码文本用小节及可识别的段首短语。分别标明作者报告、基于材料的解读、所读范围内未交代的事项。看不清的表格和公式回到原页核对；仍无法辨认就标记具体位置。

## 单张精读卡

每篇交付一张 Markdown 卡，命名为“论文短题名-精读卡.md”。清理文件名中的非法字符，同名异文以作者、年份或版本区分。

1. 读者本次指定保存位置时直接使用。否则从当前工作区或读者指定的项目确定项目根目录。外部原件、附件暂存和技能安装目录不能单独作为项目归属的依据；项目确实不明确时先请读者选项目。
2. 默认在项目的 `paper/<论文短题名>/` 下按篇归档，缺目录时直接创建。读者指定归档根或论文目录时尊重该位置。先查同版卡，保留已有分析和手记；重生成时归并旧卡和配套资源，并修正阅读历史中的链接。
3. 论文目录内保存精读卡与自行下载的同版 PDF；实际嵌图时创建 `assets/`。卡片用相对链接引用本包中的 PDF 和图表。外部提供的原件保留原路径，按需复制入包。写后检查本地链接、图片与文件，回执链接最终卡片。

以论文题名或简明陈述为主标题，卡首标出作者、出处、版本、原件与已读范围。分析采用有意义的多级标题，例如“## 三、技术方法与实验证据”“### 3.1 参考坐标系与观测模型”。小节用主题或结论命名，避免问句；双语部分保留原论文章节号与层级。借鉴研究卡中“主张—证据—边界”的组织方式，按该论文实际贡献选取层次。

- **阅读结论**。以摘要为主，按研究对象、待解决的问题、主要做法和总体成果概括全文，让首次接触论文的读者能在开头把握全貌。回到正文核对量化结论；摘要与图表矛盾时并列说明。
- **研究背景与目标**。说明应用需求、已有方案及其缺口，并指出作者实际检验的问题。学位论文附章节导读，串起各章贡献。
- **核心技术方法**。先讲核心思想和输入到输出的完整流程，再拆解各模块的输入、关键操作、输出以及模块间依赖。保留决定方法的公式、原编号和符号，解释坐标系、下标、单位、假设与物理意义；为便于理解而改写的式子标为等价表达或阅读推导。
- **实验设计与证据链**。把主要主张逐项连接到验证它的数据、对照、指标、结果和出处。说明参考真值、训练测试划分、配准与消融等影响比较的条件，并交代反例和失败情形。
- **适用边界与局限**。区分作者讨论的局限、实验证据的覆盖范围和读者推断。
- **可学到什么**。结合读者确认的研究方向、近期学习点或本次指定项目，解释可迁移的知识、迁移所需条件和可验证的问题。读者自己的延伸标为“阅读思考”。尚无画像时仍总结本文可学到的知识。

### 英文逐段对照与图表

将全文对照附在同卡末尾，按原小节排列。每个英文自然段后空一行直接接中文段落；省去逐段的“原文 · PDF 第几页”和“译文”标签，用章节、图表号及分析中的出处支持回查。逐段覆盖摘要、正文、图题表注和所读附录，保留参考文献书目信息。双栏按阅读顺序合并跨栏、跨页自然段。术语首次出现给出中英文及缩写，分清容易混淆的物理量；保留否定、推测、符号、公式编号、单位和引用号。

在相应段落旁嵌入原图或清晰裁图，保留图例、坐标轴、分图和图注。表格可原样嵌入或忠实重排为 Markdown，保留表头、数值、单位、脚注及强调含义。图片存入卡片旁的资源目录，用相对路径引用。交付前逐节核对自然段、公式、图表清单，检查图片路径、可读性和图文位置。摘要导读、术语表和页码链接均不能替代译文或图表。中文论文在需要处保留关键公式、图表与解释。

未附英文 PDF 时，主动按题名、作者和 DOI 检索出版方、作者主页、机构仓储或 arXiv，下载匹配版本，核对题名、版本、页数和补充材料，再按上面的逐段格式翻译。优先选择允许所需使用方式的版本；入口失效时继续查其他正式来源。只有经检索仍缺全文或可用范围确有缺口时，说明已取得的材料和待补范围。

## 研究画像与阅读历史

研究画像和阅读历史集中保存在本技能目录的 `private/` 子目录。读取或写入前执行[记录与更正规则](references/reading-records.md)，用已有画像选择分析重点。专业文献每次实际阅读都自动记入历史；手动调用 `$nav-reader` 完成阅读时，同步检查研究画像，并在回复中给出本次记录的可点击链接和更正、删除提示。
