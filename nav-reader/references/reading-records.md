# 研究画像与阅读历史

从当前读者的 `nav-reader/SKILL.md` 所在目录解析 `private/profile.local.md`（研究画像）和 `private/reading-history.local.md`（阅读历史）。跨项目复用这两份本地 Markdown；新安装按需创建。精读卡保存到研究项目，档案保存在个人技能安装内。多人共享安装时先确定读者自己的技能副本。

**兼容旧档案。** 首次使用时检查技能根目录下的同名旧文件。目标不存在时迁入 `private/`；已有新档时先比对、保留手写内容并合并缺失条目，有冲突时保留旧本待确认。迁入时校正因目录层级变化而失效的相对链接，读取确认后再完成迁移。旧目录的 Git 忽略规则继续有效。

**更新与分享。** Git 通过空的 `private/.gitkeep` 保留目录结构。打包、发布或同步时，该目录只包含这个占位文件。就地更新只替换技能发布文件；如果安装方式必须清空或整体替换技能目录，先把现有 `private/` 及尚未迁移的旧档案备份到替换范围以外的本机私有位置，更新后恢复并逐文件核对内容，再清理临时备份。备份失败时保留原安装。

## 何时记录

- 每次实际阅读专业相关文献后自动登记；读者手动点选、显式写出技能名或要求用本技能阅读，均算手动调用。一次读多篇，逐篇登记。仅查看档案、查题录、维护技能或调用失败未读到正文或摘要时，不新增阅读事件。本次明确要求不记录时照办。
- 正式落笔前重新读取两个文件，只修改相关条目。优先用小范围补丁保留手写内容与其他会话的记录；写入冲突则重读并合并。先保存精读卡，再登记此次实际完成的阅读和可用卡片链接。卡片或其中一份档案未能写入时，分别说明实际结果和待补项，重试只补缺项。

## 研究画像

首次使用时简短邀请读者尽可能补充研究方向、应用场景和当前问题，可跳过并继续阅读。已有画像仅含自动学习点时，也在合适机会补问一次；尊重暂不填写的选择。长期方向由读者自述或确认，近期学习点可依据实际阅读自动整理。用短条目维护长期研究方向、近期学习点和影响阅读的偏好。手动调用时主动核对：明确表达的研究方向或更正直接增改；本次确实聚焦的专业问题可带日期记入“近期学习点”（来源指向本次阅读）。单次论文主题仅支持记录一次学习活动。多次选择形成的偏好可标为“观察所得”，用户明确陈述的方向优先。一次性的翻译、版式要求仅在本篇执行。旧档案中“关闭自动记录”等明确选择按其原有范围尊重。没有新的画像信息时无需虚构变更。

## 阅读历史

每篇、每个实际阅读版本使用一个条目。用 DOI 或带版本的 arXiv ID 匹配，必要时用题名、第一作者、年份、出处与版本核验。相同论文的本地文件和链接可汇入同一条目。按“题名 · 作者 · 年份 · 出处或类型 · 版本”记录可核实的基本信息，附原文及精读卡链接。每条用两三句话从摘要提炼研究对象、问题、主要方法及总体成果，使读者按题名、关键词或研究内容都能找回论文。量化结果先核对正文；只有摘要或节选时简注材料范围。记录阅读日期，有新认识的重读可附日期和具体收获；同一版本的介绍只保留一份。省略调用方式、处理步骤和空泛的阅读范围描述。

## 回执与更正

写后回读，确认本次条目及链接落到正确文件。每次写入都在面向读者的回复里简述具体变更，附精读卡和每个实际改动档案的可点击链接，尽量直达新增条目（本地文件可用绝对路径加行号）。例如：“已把本次遮挡段评测记入〔阅读历史〕，并把‘失锁恢复’加入〔近期学习点〕。如果有出入，我可以修改或删除刚刚记下的内容。” 将示例中的括号替换为实际链接；画像未变时仅简述这一点。

收到“改一下”或“删掉刚刚的记录”时，根据上次回执和目标条目操作。若要求撤销整次记载，撤销该次新增的历史行和画像变化，更新过的旧条目恢复原先内容；保留其他日期及之后的手改。只有一个新建条目且撤销后为空时可移除其空标题。回执中说明改动并链接剩余档案。修改档案本身不会新增阅读事件。
